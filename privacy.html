Privacy policy

Last updated: 15 November 2026

Ari Uploader is a private tool run by one person for their own YouTube channels. Only that person's Google accounts are connected to it.

What it accesses

With the permission given on Google's consent screen, the tool can upload videos to the connected YouTube channel, set their title, description and tags, and read the channel's video list and statistics. It uses the YouTube API Services for this.

What it stores

The sign-in tokens Google issues are kept on the owner's own computer, in the operating system's keychain. Video files, titles and statistics stay on that computer. Nothing is stored on a server run by this tool.

What it shares

Nothing is sold or shared with anyone. Data goes only to Google and YouTube, to carry out the uploads and reads the owner asked for.

Removing access

Access can be taken away at any time on the Google security settings page. After that the tool can no longer reach the account, and the stored tokens stop working.

Other policies

The tool uses the YouTube API Services, so the YouTube Terms of Service and the Google Privacy Policy also apply.

Contact

Questions go to the developer contact shown on the app's Google consent screen.
